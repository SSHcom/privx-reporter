# PrivX Reporter v1.0.0

Initial public release of PrivX Reporter.

## Shipped Components

- Reporter CLI for running reports and generating outputs.
- Web UI for running and viewing available reports.
- Sync Server for scheduled data synchronization from PrivX into the local data store.
- Admin CLI for operational and maintenance tasks (such as migrations and back-fills).
- Shared core library used by the CLI, UI, and Sync Server.
- Sync Server live test harness for local load and integrity testing.

## Notes

- This release includes the core reporting stack and operational tooling needed to deploy and run PrivX Reporter.
- Detailed setup, operation, and development guidance is available in the project documentation.
