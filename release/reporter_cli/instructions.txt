-== Standalone installation complete ==-

If installed files are owned by root, fix permissions:

  sudo chmod -R u+rwX,g+rwX /opt/reporter

Add the PrivX Reporter binaries to the path:

  echo 'export REPORTER_HOME=/opt/reporter' >> ~/.bashrc
  echo 'export PATH="/opt/reporter/bin:$PATH"' >> ~/.bashrc
  source ~/.bashrc

Run post-install validation checks and apply security package pins:

  post_install --secure

Create the "/opt/reporter/.env" file with default database config:

  create_env --skip db

  Only configure the database if the ports 5454 and 5455 are already in use.
  To use default values for the database, sync server and ui use "--skip db sync ui"

Before starting Docker Compose:

 - Ensure these images are available either locally or in Docker Hub:
    privxsshcom/privx-reporter-sync:latest
    privxsshcom/privx-reporter-ui:latest

 - Create host directories (use values from "/opt/reporter/.env"):

    mkdir -p /opt/reporter/.volumes/data-db /opt/reporter/.volumes/admin-db
    mkdir -p <REPORT_OUT_DIR>
    mkdir -p <BACKUP_DIR>

Start sync, UI, and local databases:

  cd /opt/reporter

Two compose files are installed. Use the one that matches ENV_SOURCE in /opt/reporter/.env:

  ENV_SOURCE=db (default docker-compose.yml) — config in Admin UI after login:
    docker compose up -d

  ENV_SOURCE=env — all config in .env:
    docker compose -f docker-compose-env.yml up -d

Set the UI super-admin password before first login (bootstrap creates admin
with an unknown password):

  docker exec -it reporter-ui /opt/reporter/bin/admin_passwd

Then open https://<host>:8501 and sign in as admin.

If ENV_SOURCE=db, complete remaining settings in Admin UI -> App Config.

Verify that the reporter and admin tools can be run:

  report -h
  admin -h
